# DWBDA Assignments

This repository contains assignments completed for the Data Warehousing and Big Data Analytics (DWBDA) course.

## Assignment 1 – Market Basket Analysis

Applied Market Basket Analysis (MBA) on real-world retail transaction data using Python.

### Topics Covered
- Data preprocessing
- Apriori algorithm
- Frequent itemset generation
- Association rule mining
- Support
- Confidence
- Lift
- Data visualization

## Assignment 2 – MapReduce

Applied the MapReduce framework to calculate the number of students in each grade category (S, A, B, C, D, E, F) for different subjects.

### Topics Covered
- Mapper
- Reducer
- Grade-wise student count
- Subject-wise analysis

## Assignment 3 – Spark Sales Analysis

Used Apache Spark to calculate the number of products sold in each category.

### Topics Covered
- PySpark
- Data loading
- GroupBy
- Aggregation
- Category-wise product quantity
